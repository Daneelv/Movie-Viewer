## 📜 About

I built this as a demo for a client to showcase my work. I used a local mongo DB connection to persist my data and the moviedb api to retreive the movie info

---

## ✨ Features

- ✅ Search for movies
- ✅ Register/ login
- ✅ Add Movies to favourites

---

## 🛠 Tech Stack

**Frontend:** Next.js, TailwindCSS  
**Backend:** Nodejs
**Database:** Mongo DB

## ⚙️ Installation

```bash
# You will need to install the following:

# Clone the repo
git clone https://github.com/Daneelv/Movie-Viewer.git

# front end (client) :

1. a good web browser

# NodeJs Dependencies

1. body-parser : V1.19.0
2. cors: V2.8.5
3. express: V4.17.1
4. jsonwebtoken: V8.5.1
5. mongoose: V5.9.5

# Built With

1. NodeJS
2. Express
3. Javascript
4. Mongo DB
5. VS Code

# Running the server

1.  Install NodeJS and MongoDB
2.  Install all of Node Dependencies
3.  Navigate to the root of the server path in a terminal
4.  Run the follwing command _node server.js_
5.  you should see the following messages:

    > Server is listening on port 3000

    > Successfully connected to the database

# Runnig the Client

1. Navicate to the client folder
2. Open Index.html in your browser
```
